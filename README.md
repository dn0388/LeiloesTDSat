# Sistema Casa de Leilões

## 📌 Sobre o Projeto
Sistema desenvolvido em Java para gerenciar produtos em uma casa de leilões. 
Permite cadastrar produtos, listar produtos cadastrados, realizar vendas e consultar produtos vendidos.

## 🛠 Tecnologias Utilizadas
- Java
- MySQL
- Git
- GitHub

## 💾 Banco de Dados
O sistema utiliza o banco de dados MySQL com as tabelas:
- produtos
- vendas
